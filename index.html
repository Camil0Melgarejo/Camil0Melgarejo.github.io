Proyecto universitario · 2025
RepCampus
Aplicación móvil de gestión de reportes para campus universitarios

RepCampus es una aplicación móvil diseñada para facilitar el reporte y seguimiento de daños o incidencias dentro de un campus universitario. Los estudiantes y personal pueden registrar reportes con fotos, ubicación y descripción, mientras que los administradores gestionan y resuelven cada caso desde un panel centralizado. El proyecto está siendo desarrollado con un stack de nivel enterprise, con miras a escalar a múltiples instituciones.
